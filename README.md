# 🏋️ Gym Management System

A **full-stack Gym Management System** built with **.NET Core** (backend) and **Angular 17** (frontend).  
This system streamlines the management of clients, trainers, classes, schedules, and appointments — all in one place.  
Perfect for gyms looking to automate admin tasks, track member progress, and enhance client engagement.

## 📋 Features

### 👑 Admin Features
- **Full CRUD** for:
  - Clients
  - Trainers
  - Classes
  - Schedules
  - Appointments
  - Other Admin accounts
- Assign appointments by selecting a trainer, a client, and a session date.
- Limit the number of clients per session.
- Email verification for new users.
- Send special offers to all verified users.
- Search:
  - Appointments by date
  - Clients by name, mobile, or national ID

### 🧍 Client Features
- View booked appointments.
- Comment on sessions (visible to admins).
- Upload a picture after each session to track fitness progress.

### 🏋️ Trainer Features
- View and manage assigned appointments.
- Record client cases (visible to clients).
